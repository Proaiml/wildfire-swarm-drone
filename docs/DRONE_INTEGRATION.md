# PyreSwarm - Drone Entegrasyon ve Donanım Adaptör Rehberi (Drone Integration)

## 1. Mimarisi
Tüm fiziksel ve sanal hava araçları `DroneAdapter` soyut arayüzünü uygular.

```python
class DroneAdapter(ABC):
    def connect(self, connection_url: str) -> bool: ...
    def disconnect(self): ...
    def arm(self) -> bool: ...
    def disarm(self) -> bool: ...
    def takeoff(self, target_altitude_m: float) -> bool: ...
    def land(self) -> bool: ...
    def return_to_home(self) -> bool: ...
    def goto(self, lat: float, lon: float, alt: float, speed_ms: Optional[float]) -> bool: ...
    def set_velocity(self, vx: float, vy: float, vz: float) -> bool: ...
    def get_state(self) -> DroneState: ...
```

## 2. Destek Durumu [SCIENTIFIC INTEGRITY]

| Adaptör Tipi | Doğrulama Durumu | Kullanım Amacı |
| :--- | :--- | :--- |
| `SimulationDroneAdapter` | **MEASURED & VALIDATED** | 6-DOF kinematik, sentetik kamera, deterministik testler |
| `MAVSDKDroneAdapter` | **PARTIALLY_VALIDATED** | PX4 ve ArduPilot MAVLink otopilotları (Laboratuvar aşamasında) |
| `DJI_SDKAdapter` | **PLANNED / ROADMAP** | DJI Mobile/Onboard SDK köprüsü (Gelecek sürüm) |
| `VolunteerRESTAdapter` | **MEASURED & VALIDATED** | Sivil/gönüllü drone'ların web arayüzü üzerinden GPS/kamera yayını |
